# Code of Conduct

LIQ OS contributors are expected to keep collaboration professional, evidence-oriented, and respectful.

## Standards

- Assume shared intent, but verify decisions with written rationale.
- Challenge ideas through evidence, not authority.
- Keep discussion focused on user outcomes, accessibility, safety, privacy, and implementation quality.
- Do not use personal attacks, harassment, discriminatory language, or dismissive behavior.
- Respect that health-related software requires unusual care around user trust.

## Enforcement

Maintainers may close discussions, reject changes, or restrict participation when conduct interferes with constructive work.
