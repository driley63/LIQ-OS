# Volume 01 - Brand Identity

Volume 01 defines the approved LifestyleIQ brand identity and the implementation rules needed to apply it consistently across product, web, app stores, marketing, and internal documentation.

## Status

- Current milestone: v1.1.0 draft
- Owner: Brand Working Group
- Review path: Pull request review by LIQ OS maintainers
- Release target: minor release because this work adds implementation standards without changing the approved brand direction

## Approved Baseline

- Product name: LifestyleIQ
- Operating system: LIQ OS
- Philosophy: "Translating daily habits into a plan towards optimal health."
- Signature gradient: Fresh Lime to Evergreen
- AI color: Purple reserved for AI-generated insights
- Primary typeface: Inter
- Brand tone: intelligent, calm, positive, scientific, optimistic, human, data-driven, premium, and trustworthy

## Current Milestone

The v1.1.0 draft turns the baseline direction into reviewable implementation standards. It focuses on brand decisions that teams need before creating production app icons, launch assets, UI tokens, Figma libraries, marketing pages, and code exports.

## Document Map

- `SPEC.md`: volume-level rules, scope, and acceptance criteria
- `brand-story.md`: narrative, philosophy, and brand promise
- `positioning.md`: audience, category, differentiation, and proof points
- `logo-system.md`: approved mark architecture and asset roles
- `logo-construction.md`: construction rules and optical refinement requirements
- `logo-usage.md`: clear space, minimum sizes, backgrounds, and misuse rules
- `color-system.md`: primitive colors, semantic roles, gradients, and AI color reservation
- `typography.md`: Inter usage, type scale, fallback policy, and wordmark separation
- `design-tokens.md`: token taxonomy, naming rules, platform mappings, and change controls
- `iconography.md`: icon style, stroke, metaphor, and AI icon rules
- `accessibility.md`: contrast, color independence, motion, and legibility requirements
- `brand-governance.md`: change review, approvals, release handling, and audit trail
- `asset-production.md`: source files, export sets, manifests, and delivery requirements

## Acceptance Criteria

- Brand decisions can be implemented in Figma, CSS, Flutter, iOS, Android, and MkDocs without one-off interpretation.
- Logo and icon assets have a documented source-of-truth path and generated export requirements.
- Purple remains reserved for AI and machine-learning behavior.
- Any future brand change has a clear review, RFC, ADR, and release path.
