# ADR-0005: Adopt the Versioned LIQ OS Model

Status: Accepted
Date: 2026-08-03
Owner: LIQ OS Maintainers

## Context

The project needed a way to prevent approved decisions from drifting as brand, design, engineering, and AI standards grow.

## Decision

LifestyleIQ Operating System (LIQ OS) is the versioned source of truth for product standards.

## Alternatives Considered

- Single branding guide
- Unversioned documents
- Keep decisions only in chat history

## Consequences

- Specifications are treated like software artifacts.
- Releases provide stable references for implementation teams.
- Future apps can depend on specific LIQ OS versions.

## Traceability

- Core principle: implementation-first standards
- Release: v1.0.1
