# Release Notes - v1.3.0

Date: 2026-08-04
Status: Draft minor

## Summary

This release candidate starts the Volume 03 Product Experience implementation milestone. It builds on Brand Identity v1.1.0 and Design Language v1.2.0 by defining practical product behavior for daily health workflows, evidence-backed insights, reports, consent, notifications, and user research.

## Added

- Expanded Volume 03 overview with milestone status, principles, document map, and acceptance criteria.
- Product Experience specification with system boundaries, dependencies, pattern definition of done, and review requirements.
- Experience principles, daily logging, health timeline, insight, correlation, report, onboarding, consent, notification, health-language, and user-research standards.
- Draft v1.3.0 release manifest, checklist, and release notes.

## Changed

- MkDocs navigation now exposes the full Product Experience volume.
- Product Experience docs now describe implementation standards instead of generic baseline intent.
- Release index now includes the v1.3.0 draft minor release candidate.

## Deprecated

- None.

## Removed

- None.

## Known Limitations

- Product examples are textual standards only; production flows, prototypes, analytics specs, and user-research artifacts are not yet included.
- Formal review against Brand Identity v1.1.0, Design Language v1.2.0, and AI Principles remains pending before release promotion.
