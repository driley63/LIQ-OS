# LIQ OS v1.3.0

Status: Released minor
Date: 2026-08-04

v1.3.0 releases the Volume 03 Product Experience implementation milestone. It turns baseline product topics into implementation-ready standards for daily logging, timelines, insights, reports, onboarding, consent, notifications, health language, and research.

## Included Areas

- Volume 03 Product Experience specification refinement
- Product experience principles and workflow definition of done
- Daily logging, health timeline, insight, correlation, and report standards
- Onboarding, settings, consent, notification, and health-language requirements
- User research standards for health-sensitive product decisions
- Cross-volume review against Brand Identity v1.1.0, Design Language v1.2.0, and AI Principles
- MkDocs navigation expansion for the Product Experience volume

## Release Decision

This is a minor release because it adds implementation standards without changing released Brand Identity, Design Language, LIQ OS Core, or AI Principles decisions.
