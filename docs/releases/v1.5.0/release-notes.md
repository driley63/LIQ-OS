# Release Notes - v1.5.0

Date: 2026-08-04
Status: Draft minor

## Summary

This release candidate expands the released Design Language into prototype-facing UI pattern standards. It fills gaps for app shell, navigation, page templates, collections, overlays, feedback, search, filters, sorting, progress, and disclosure before backend implementation work continues.

## Added

- App shell and navigation standards for top bars, bottom navigation, side navigation, tabs, breadcrumbs, route labels, and recovery navigation.
- Page template standards for dashboard, detail, form, report, settings, onboarding, and empty-state screens.
- Lists and tables standards for rows, grouped collections, timeline rows, dense data, responsive alternatives, and collection states.
- Overlays and feedback standards for dialogs, sheets, banners, toasts, confirmations, inline feedback, focus behavior, and severity mapping.
- Search, filter, and sort standards for query summaries, active constraints, result states, privacy-safe query handling, and accessible controls.
- Progress and disclosure standards for steppers, progress bars, skeletons, spinners, accordions, show-more controls, and optional detail.
- Draft v1.5.0 release manifest, checklist, and release notes.

## Changed

- Volume 02 Design Language specification now identifies v1.5.0-draft and includes the expanded UI pattern scope.
- Volume 02 overview now lists the new UI Pattern Expansion documents.
- MkDocs navigation now exposes the new UI Pattern Expansion documents.
- Release index now includes the v1.5.0 draft minor release candidate.

## Known Limitations

- UI pattern examples are textual standards only; production Flutter components, Widgetbook stories, and interactive prototypes remain future implementation artifacts.
- Cross-volume review remains pending before release promotion.
