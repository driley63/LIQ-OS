# Release Notes - v1.1.0

Date: 2026-08-04
Status: Draft minor

## Summary

This release candidate starts the Volume 01 Brand Identity implementation milestone. It keeps the approved LifestyleIQ brand direction intact while making the brand system easier to implement, review, and govern.

## Added

- Expanded Volume 01 overview with milestone status, document map, and acceptance criteria.
- Brand specification boundaries, governance requirements, and definition of done.
- Color primitive palette, signature gradient rules, semantic color roles, and AI color reservation guidance.
- Design token layers, required token names, platform mapping rules, and change-control rules.
- Logo usage rules for asset roles, clear space, minimum sizes, backgrounds, and misuse.
- Asset production requirements for source locations, export sets, inventory, and quality gates.
- Brand governance rules for change classes, review gates, approval ownership, and exceptions.
- Logo placeholder optical refinement review with production blockers and refinement gates.
- Draft v1.1.0 release manifest and checklist.

## Changed

- Brand docs now describe implementation standards instead of only baseline intent.
- MkDocs navigation now exposes more of the Brand Identity volume.
- Logo asset README now distinguishes placeholder masters from future production exports.
- Logo Construction now defines optical refinement gates for final logo approval.

## Deprecated

- None.

## Removed

- None.

## Known Limitations

- Logo SVGs remain placeholder masters pending final optical refinement.
- Production generated logo exports and asset inventory are not yet checked in.
