- Volume 04 Engineering Standards specification refinement

- Testing, accessibility testing, CI/CD, observability, security, privacy, performance, and release engineering requirements
- Engineering definition of done covering testability, observability, privacy, accessibility, and release impact
- Cross-volume review against Brand Identity v1.1.0, Design Language v1.2.0, Product Experience v1.3.0, and AI Principles
- MkDocs navigation expansion for the Engineering Standards volume

## Release Decision

This is a minor release because it adds implementation standards without changing released Brand Identity, Design Language, Product Experience, LIQ OS Core, or AI Principles decisions.
