## Purpose

Defines why LifestyleIQ and LIQ OS exist.

## Scope

- Product mission
- System mission
- Audience
- Relationship to implementation

## Requirements

- LifestyleIQ must help users understand how daily habits affect health.
- LIQ OS must make product decisions reusable and traceable.

## Implementation Guidance

- Connect every major specification back to user understanding, action, and safety.
- Avoid standards that exist only for internal preference.

## Acceptance Criteria

- The mission can be quoted from the document.
- Every volume includes a traceable relationship to the mission.
