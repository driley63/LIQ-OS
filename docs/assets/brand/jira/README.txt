Jira Brand Assets
=================

These files provide compact LifestyleIQ icon exports for Atlassian Jira surfaces.

Files
-----

- lifestyleiq-jira-icon.svg: source SVG master derived from the current LifestyleIQ icon asset
- lifestyleiq-jira-favicon-32.png: Jira favicon export, 32 x 32 px
- lifestyleiq-jira-portal-icon-50.png: Jira Service Management portal logo export, 50 x 50 px
- lifestyleiq-jira-logo-57x30.png: Jira application logo export, 57 x 30 px

Usage
-----

- Use the 32 px PNG for Jira favicon fields.
- Use the 57 x 30 PNG for Jira application logo fields.
- Use the 50 px PNG for Jira Service Management portal logo fields.

Source Note
-----------

These exports are derived from the current source-controlled LifestyleIQ icon. Replace them when final production logo masters are approved.
