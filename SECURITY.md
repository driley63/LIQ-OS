# Security Policy

LIQ OS defines standards for health-related product work. Even documentation changes can affect user privacy and safety.

## Reporting

Do not open public issues for suspected security or privacy vulnerabilities. Report privately to the repository owner.

## Security Review Triggers

- Any change involving health data, personally identifiable information, authentication, authorization, encryption, AI-generated recommendations, exports, or integrations.
- Any change that could alter user consent, data retention, deletion, or sharing expectations.
- Any change that could cause users to interpret LifestyleIQ as diagnostic medical software.

## Baseline Requirement

Specifications must avoid prescribing implementation details that weaken privacy, user control, or explainability.
