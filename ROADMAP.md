# Roadmap

LIQ OS evolves in milestones. Dates are intentionally omitted until implementation capacity is known.

## Milestone 1 - Foundation

- LIQ OS Core
- Governance
- ADR templates
- RFC templates
- Repository structure
- Documentation site

## Milestone 2 - Brand

- Logo system
- Wordmark refinement
- Color system
- Typography system
- Design tokens

## Milestone 3 - Design

- Spacing and layout
- Motion
- Accessibility
- Component standards
- Iconography

## Milestone 4 - Engineering

- Flutter architecture
- Design system package
- Widgetbook
- Testing standards
- CI/CD

## Milestone 5 - Product and AI

- UX principles
- AI insight behavior
- Health-domain language
- Explainability and confidence standards
